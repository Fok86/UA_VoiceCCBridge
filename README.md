# UA Voice CC Bridge 🎮🔊

Плагін для [Decky Loader](https://github.com/SteamDeckHomebrew/decky-loader) який озвучує субтитри в іграх на Steam Deck українською мовою через синтез мови.

> ⚠️ **Важливо:** Плагін **не робить переклад**! Він лише зчитує та озвучує субтитри які вже є в грі. Гра повинна мати вбудовані українські субтитри — інакше плагін працюватиме некоректно.

## Як це працює

Плагін робить знімок зони субтитрів на екрані, розпізнає текст через OCR і озвучує його через синтезатор мови Piper.

```
Знімок екрану → OCR (Tesseract) → Синтез мови (Piper / RHVoice) → Звук
~200мс          ~100мс             ~160мс
```

Загальна затримка від появи субтитрів до озвучення: **~300мс**

## Можливості

- 🔊 Синтез мови українською (8 голосів: Piper + RHVoice)
- 🎮 Профілі налаштувань для кожної гри окремо

## Встановлення

### Спосіб 1 — Вручну ✅

1. Завантаж zip з **[Releases](https://github.com/Fok86/UA_VoiceCCBridge/releases/latest)**
2. Розпакуй в `/home/deck/homebrew/plugins/`
   - Має вийти папка `/home/deck/homebrew/plugins/UA_VoiceCCBridge/`
3. Перезапусти Decky через термінал:
   ```
   sudo systemctl restart plugin_loader
   ```

### Спосіб 2 — Через Decky Store

*(Очікується у майбутніх релізах)*

## 🚀 Перший запуск — покроково

**1. Запусти гру з українськими субтитрами**

**2. Відкрий плагін → "Зона субтитрів"**
- Натисни **"Зробити знімок"**
- Налаштуй відступ, ширину, висоту щоб субтитри потрапили в рамку
- Дивись на превью — субтитри мають бути видні
- Натисни **"Зберегти"**

**3. Відкрий "Фільтри зображення"**
- Вибери колір субтитрів (W=білі, Y=жовті)
- Якщо субтитри з обводкою → увімкни **Outline filter**
- Дивись на превью — текст має бути чітким
- Натисни **"Зберегти"**

**4. Відкрий "OCR" → натисни "Тест OCR"**
- Перевір що текст розпізнався правильно
- Якщо погано — повернись до кроку 3

**5. Відкрий "Синтез мови"**
- Вибери голос
- Натисни **"Тест голосу"** щоб перевірити звук
- Натисни **"Зберегти"**

**✅ Готово! Грай — плагін читатиме субтитри автоматично**

## Налаштування

### Зона субтитрів
Вкажіть де на екрані знаходяться субтитри. Використовуйте кнопку **Зробити знімок** для перевірки.

### Фільтри зображення
Налаштуйте контраст, яскравість та кольоровий фільтр для кращого розпізнавання тексту. Превью оновлюється в реальному часі.

### OCR
- **Інтервал** — як часто робити знімок (мс)
- **Мін. довжина** — мінімальна кількість символів для озвучення
- **Фільтр повторів** — поріг схожості для фільтрації дублікатів

### Синтез мови
- **Голос** — Микита / Лада / Тетяна / Даринка / Anatol / Volodymyr / Natalia / Marianna
- **Швидкість** — швидкість читання (0.5x–2.5x)
- **Гучність** — гучність озвучення
- **Живість голосу** — варіативність інтонації *(тільки Piper)*
- **Дихання** — природність переходів між звуками *(тільки Piper)*
